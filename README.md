# Screen Fabricator

Created by Bryce P Mulligan, PhD, CPsych

## Overview

Screen Fabricator is a Streamlit application that enables clinicians, researchers, and other subject-matter experts to create custom screening, intake, triage, and decision-support tools without programming.

The application was developed to make the process of creating structured screening workflows more accessible to individuals with clinical expertise who may have little or no software-development experience.

## Current Status

Current Release: V07 Pilot

Screen Fabricator is currently undergoing pilot testing and refinement.

## Key Features

- Questionnaire-based scoring
- Total-score-entry workflows
- Symptom elevation thresholds
- Critical-item safety alerts
- Custom interpretations
- Custom next-step guidance
- Detailed recommendations and resources
- Scoring simulator
- JSON export of tool definitions
- Tool transparency and auditability

## Intended Users

- Psychologists
- Physicians
- Nurses
- Allied health professionals
- Researchers
- Program managers
- Community organizations
- Quality-improvement teams

## Design Principles

Screen Fabricator is guided by the following principles:

- No programming required
- Transparency over complexity
- Clinician-friendly language
- Flexible workflow design
- Safety-conscious decision support
- Visible guidance rather than hidden functionality

## Important Note

Screen Fabricator is a prototype application.

Users are responsible for ensuring that any screening workflow created with the software is appropriate for its intended purpose and context.
