# Screen Fabricator

Created by Bryce P Mulligan, PhD, CPsych

## Overview

Screen Fabricator is a Streamlit application that allows clinicians, researchers, and other subject-matter experts to create customized screening and triage tools without programming.

Features include:

- Questionnaire-based scoring
- Total-score workflows
- Critical safety-item tracking
- Safety Alerts
- Symptom elevation thresholds
- Recommendations and next-step guidance
- JSON export of tool definitions
