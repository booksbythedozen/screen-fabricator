# Screen Fabricator V07

## Purpose

V07 focuses on usability, transparency, documentation, and pilot testing readiness.

Rather than introducing substantial architectural complexity, this release prioritizes making the application easier for clinicians to understand and evaluate.

## Major Changes

### Home Page Redesign

The Home page now emphasizes the application's primary purpose:

- Screening tool creation
- Clinical screening workflows
- Intake processes
- Research enrolment

### Improved Clinical Language

Colour-based severity labels were reduced in importance.

Users now see:

- Low Symptom Elevation
- Moderate Symptom Elevation
- Severe Symptom Elevation

This reduces ambiguity during interpretation.

### Tool Transparency

Tool definitions can now be downloaded as JSON files.

Benefits:

- Easier auditing
- Version comparison
- Sharing with colleagues
- Documentation support

### Enhanced Results Reporting

Result pages now display:

- Total score
- Clinical interpretation
- Next steps
- Recommendations

### Pilot Testing Enhancements

The application now encourages structured feedback collection regarding:

- Confusing elements
- Unnecessary complexity
- Missing functionality
- Improvement ideas

## Deferred Features

Future releases may consider:

- Tool import functionality
- Persistent storage
- PDF report generation
- Conditional branching logic
- Multi-page workflows
- User administration

## Release Philosophy

This release emphasizes simplicity, transparency, and clinician usability over feature expansion.
