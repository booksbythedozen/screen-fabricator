# Screen Fabricator V05 - Development Plan

## Project Vision

Screen Fabricator is a prototype application designed to help clinicians create, test, and administer custom mental health screening and triage workflows without programming expertise.

## Author

Bryce P Mulligan, PhD, CPsych

## Design Principles

- Mental-health-focused
- Designed for non-technical users
- Flexible but intuitive
- Clear separation of symptom elevation and immediate safety concerns
- Rapid prototyping and feedback-driven development

## V05 Objectives

- Expand and improve Home page
- Improve onboarding and orientation
- Replace manual safety checkbox with critical-item logic
- Move Recommended Actions after scoring simulation
- Replace numeric sliders with numeric entry fields
- Improve visibility of Purple safety alerts
- Prepare application for pilot testing

## Pilot Testing Plan

Target: 5-10 colleagues

Suggested Tasks:
1. Build a screening tool
2. Configure scoring thresholds
3. Configure safety triggers
4. Save the tool
5. Use the tool and calculate results

## Feedback Questions

1. Did you find anything confusing, unintuitive, or overly complicated?
2. Did you encounter any bugs or unexpected behaviour?
3. What is the single most useful improvement you would make?
4. Any other comments or suggestions?

## Success Criteria

- Users can build tools independently
- Users understand scoring logic
- Users understand safety-trigger logic
- Few major usability concerns identified
- Interest in adopting and sharing tools
