# Screen Fabricator V06 Development Plan

## Theme
Faster Tool Creation. Clearer Clinical Guidance.

## Scope
- Global response templates
- Reverse scoring
- Safety Alert terminology
- Severity-first labels
- Brief Next Steps
- Detailed Recommendations & Resources
- Expandable recommendation panels
- Improved safety guidance

## Acceptance Criteria
1. PHQ-9 style tools can be built with a shared response template.
2. Reverse-scored items calculate correctly.
3. Results display Next Steps and expandable Recommendations.
4. Safety Alerts remain independent from symptom severity.
5. User-facing labels use Low/Moderate/High Symptom Elevation.
