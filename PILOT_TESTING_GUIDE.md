# Screen Fabricator V07 Pilot Testing Guide

Thank you for testing Screen Fabricator.

Estimated time: 10–15 minutes.

## Purpose

Screen Fabricator is a prototype application designed to help clinicians create, test, and administer custom screening and triage workflows without programming expertise.

## Suggested Tasks

1. Build a simple screening tool.
2. Configure symptom-elevation thresholds.
3. Configure at least one critical safety item.
4. Test the Scoring Simulator.
5. Use the completed tool.
6. Review outputs and recommendations.
7. Export the tool definition as JSON.

## Feedback Questions

### Usability

- Did you find anything confusing?
- Did you find anything unnecessarily complicated?
- Was any part of the process difficult to understand?

### Bugs

- Did anything fail to work as expected?
- Did you encounter any errors?

### Enhancements

- What is the single most useful improvement you would make?
- What capability would you most like to see added?

### Overall Impression

- Would you use a tool like this in practice?
- Who else might benefit from it?
